🛡️ 0. Inizializzazione, Permessi & Locking
0 Verifica Privilegi Root & Lock Esclusivo
Esecuzione Non-Root (UID != 0)
Richiede password con exec sudo "" "$@" e riavvia lo script preservando i parametri CLI.
Lock File Occupato (/run/luks-manager.lock)

Buffer Sicuro STDIN in RAM
Se lo script riceve la chiave via pipe o socket, la salva subito su file temporaneo in RAM (/dev/shm/luks_key.XXXXXX con permessi 600).

🔀 1. Dispatch Comandi
Comando: status
Interroga HA, Volume Group, LUKS, Mount e WebDAV. Stampa il report in console ed esce con exit 0 senza modificare nulla.
Comando: stop / lock
Salta direttamente alla Sequenza di Teardown Sicuro in fondo.
Comando: start / unlock
Arma le trap di sicurezza per i segnali (SIGINT, SIGTERM, SIGHUP) e procede alle fasi di avvio.
↓
🟢 2. Sequenza di Avvio & Sblocco (Start / Unlock)
1 Alimentazione Presa 220V (Home Assistant)
Home Assistant Abilitato
Invia curl POST /api/services/switch/turn_on con timeout rigidi di 4s. Attende in polling fino a HA_WAIT_TIMEOUT (15s) la conferma state: "on".
Errore Connessione / Timeout Presa
Se HA è irraggiungibile o la presa non si accende entro 15s: notifica Discord, arresta la procedura ed esce (senza toccare il disco).
Home Assistant Disabilitato
Se ENABLE_HOME_ASSISTANT=false, salta direttamente all'attesa disco.
↓
2 Rilevamento Hardware sul Bus USB & Spin-up
Loop di Rilevamento (max 40s)
Attende che il disco completi lo spin-up meccanico. Esegue pvscan e vgscan --mknodes cercando il Volume Group configurato (mybook).
Disco Non Rilevato Entro 40s
Notifica Discord di errore ed esegue il Teardown di sicurezza (spegnendo la presa 220V per non lasciarla accesa a vuoto).
↓
3 Attivazione LVM (Volume Group)
Attivazione Nodi Logici
Esegue vgchange -ay mybook. Rende disponibili i nodi /dev/mybook/crypto_data e /dev/mybook/backup_data nel kernel.
↓
4 Sblocco Crittografico LUKS2 in RAM
Caso A: File Chiave CLI (--keyfile)
Sblocca con cryptsetup open /dev/mybook/crypto_data cryptovault --key-file <path>.
Caso B: STDIN / WebUI Stego Socket
Passa il file temporaneo in RAM da /dev/shm, sblocca il volume e fa subito shred -u del buffer di memoria.
Caso C: TTY Interattivo (Passphrase)
Prompt mascherato da terminale (fino a 3 tentativi massimi).
Chiave / Passphrase Errata
Se lo sblocco fallisce: notifica Discord di allarme, azzera la variabile di memoria e avvia il Teardown Sicuro con spegnimento della presa.
↓
5 Montaggio Filesystem Unificato & Avvio Servizi
Mount Dati Cifrati (ext4)
Monta /dev/mapper/cryptovault su /srv/storage/crypto_data con flag noatime,nodev,nosuid. Applica permessi gruppo storage (SGID 2775).
Mount Secondo Volume (Opzionale)
Se configurato LV_BACKUP, monta /dev/mybook/backup_data su /srv/storage/backup_data con permessi gruppo storage.
Riavvio WebDAV / Samba
Aggiorna la radice in /etc/webdav/config.yaml e riavvia webdav.service.
↓
6 Modalità di Esecuzione & Watchdog Inattività
Modalità Demone / WebUI (--no-watchdog)
Disarma la trap di uscita e termina lo script con exit 0 lasciando lo storage montato e pronto all'uso.
Modalità Interattiva da Terminale CLI
Resta in ascolto: monitora le statistiche di I/O del disco ogni 15s. Se non ci sono letture/scritture per più di IDLE_TIMEOUT_MIN (o se l'utente preme INVIO), avvia il Teardown automatico.

🛡️ 3. Sequenza di Teardown & Arresto Sicuro (safe_power_off_sequence)

Questa sequenza è atomica e irreversibile. Viene protetta disabilitando i segnali di interruzione (trap '' ERR SIGINT SIGTERM) per garantire che nessuna fase venga saltata.

1. Stop del Servizio WebDAV
Esegue systemctl stop webdav chiudendo all'istante tutte le sessioni di rete dei client Windows/Mac/Linux per bloccare nuove scritture.
2. Flush dei Buffer di Memoria (sync)
Esegue sync per scaricare forzatamente tutti i blocchi dalla page cache della RAM sui piatti del disco fisico.
3. Smontaggio Filesystem (umount)
Termina processi rimasti aperti con fuser -km -9 sui mountpoint. Smonta /srv/storage/crypto_data e /srv/storage/backup_data (con fallback su lazy unmount umount -l se occupati).
4. Chiusura Container LUKS (Sigillo RAM)
Esegue cryptsetup close cryptovault (con retry fino a 3 volte e fallback dmsetup remove -f). La Master Key viene istantaneamente distrutta dalla memoria volatile.
5. Disattivazione Volume Group LVM
Esegue vgchange -an mybook rilasciando tutti i descrittori logici del kernel.
6. Parcheggio Meccanico Testine SCSI (STOP UNIT)
Invia il comando hardware udisksctl power-off -b /dev/sdX. Attende che il kernel confermi la disconnessione (fino a 10s) oppure applica una pausa di SPINDOWN_WAIT_SEC (3s) per consentire alle testine di raggiungere la rampa di parcheggio.
7. Pausa di Tolleranza & Taglio Alimentazione 220V
Attende la pausa di grazia CUTOFF_GRACE_SEC (5s) per garantire che i dischi siano completamente fermi. Invia curl POST /api/services/switch/turn_off a Home Assistant. Lo storage scende a 0 Watt di consumo.
